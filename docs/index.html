它能做什么

🎧

语音组一起听

音乐通过 Simple Voice Chat 播放，同组玩家都能听到，距离衰减自然。

🌐

多音源

B 站、网易云、酷狗、酷狗概念版、YouTube、SoundCloud、直链。

💛

我的音乐

收藏歌曲、自建歌单，每位玩家独立存储，可单独播放或删除。

🖥

图形菜单

Paper 1.21.7+ 的播放器式界面：搜索、队列、音量、设置、登录。

📜

滚动歌词

ActionBar 跟随进度，网易云 / 酷狗官方 LRC，可调颜色与字体。

🔁

播放模式

顺序 / 单曲循环 / 列表循环，队列上限 1000 首。

🔑

会员共享

管理员扫码一次，全服共享网易云 / 酷狗会员曲库。

🚫

零缓存

只解析音频流，不下载、不占磁盘。

新增音源：酷狗 / 酷狗概念版

🐧

酷狗音乐

搜索、播放、扫码登录、Cookie 兜底，会员歌曲可放。

✨

酷狗概念版

独立 appid、独立 CDN、独立会员体系，与标准版互不影响。

🏷

VIP 标识

会员 / 付费歌曲显示金色 [VIP]，聊天栏、菜单、全部音源一致。

📝

酷狗歌词

官方 LRC，按播放进度滚动，缓存后不再重复请求。

B 站✅—BV/av、番剧、b23.tv，支持分 P
网易云✅✅ 扫码歌曲 / 歌单，登录后放会员歌

常用指令

指令说明
/music play <链接 | 歌名>播放链接，或按默认音源搜索后播放
/music search <关键词>聊天栏搜索，可翻页
/music now-playing | queue当前播放 / 队列
/music skip | pause | resume | stop播放控制
/music volume | bassboost音量 / 低音
/music loop <off|one|all>循环模式
/music source <…>默认音源切换
/music menu图形菜单
/music collect [标识] [标题]收藏歌曲（不带参数收藏当前播放）
/music catalogue管理收藏歌单
/music login <netease|bilibili|kugou|kugouconcept>管理员扫码登录
/music lang | kill | register语言 / 重置播放器 / 重注册服务

安装

① 安装语音

服务器安装 Simple Voice Chat（服务端插件 + 客户端 mod）。

② 放入插件

把 SimpleVoiceChatMusic-3.3.0.jar 放进 plugins/ 并重启。

③ 可选登录

管理员执行 /music login kugou 或 netease 扫码。

④ 开听

玩家加入语音组 → /music menu 或 /music play 歌名。

配置摘要

music:
  max-queue-size: 1000        # 队列上限
  max-search-results: 10      # 聊天栏搜索每页条数
  default-source: "all"       # 默认音源
  all-sources:
    youtube: false
    soundcloud: false
    per-source-limit: 10      # 全部音源每源条数

menu:
  enabled: true
  queue-page-size: 20
  search-results: 100         # 菜单搜索最多展示条数

lyrics:
  enabled: true
  color: "blue"
  bold: true
